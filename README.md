#  Education Tracker

Education Tracker — iOS‑приложение для учёта учебных задач, дедлайнов и оценок. Позволяет планировать задания, отслеживать прогресс и контролировать успеваемость в одном месте.


##  Цели и задачи

- **Автоматизация и упрощение учебного процесса**  
  Сведение к минимуму рутинной работы учеников, преподавателей и администраторов.

- **Повышение вовлеченности и успеваемости студентов**  
  Доступ к информации о собственном прогрессе мотивирует обучающихся, помогает ориентироваться в учебе в реальном времени.

- **Улучшение качества образования**  
  Своевременный анализ успеваемости позволяет корректировать программы с любого устройтва.


## Основные функции платформы

1. **Управление курсами**
   - Добавление и редактирование курсов
   - Назначение преподавателей
   - Настройка расписания занятий

2. **Управление пользователями**
   - Регистрация студентов и преподавателей
   - Назначение ролей и прав доступа

3. **Отслеживание прогресса**
   - Ведение баллов и оценок
   - История выполненных заданий
   - Уведомления о дедлайнах

4. **Аналитика и отчётность**
   - Статистика по каждому курсу и студенту
   - Сравнительный анализ групп и преподавателей
   - Выгрузка отчетов в различных форматах

5. **Интерфейс для студентов**
   - Просмотр курсов и заданий
   - Отправка выполненных заданий
   - Получение обратной связи от преподавателей

6. **Интерфейс для преподавателей**
   - Проверка работ
   - Оценивание
   - Комментирование прогресса студентов

7. **Интерфейс для администраторов**
   - Полный контроль над курсами, пользователями и статистикой



## Преимущества использования перед другими платформами

- Интуитивно понятный интерфейс для всех категорий пользователей
- Гибкость в настройке курсов и пользовательских ролей
- Полный контроль над образовательной аналитикой
- Масштабируемость для работы с разными типами учебных заведений
- Минимизация административных затрат
